## Stack

- **Language**: TypeScript
- **File types**: `.ui` (logic), `.uix` (components)
- **Package scopes**: `@swissjs/*` (framework), `@sws/*` (app packages)
- **Build**: [swite](https://github.com/kibologic/swite) — esbuild-based, HMR included
- **Package manager**: pnpm workspaces
